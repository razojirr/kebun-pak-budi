Kebun Pak Budi - Website versi aplikasi

Fitur:
- Login
- Dashboard
- Database SQLite (data tersimpan di kebun.db)
- Pengeluaran dan utang toko
- Hasil panen
- HPP dan rekomendasi harga jual
- Penjualan dan laba/rugi
- Laporan transaksi
- Reset data

Cara menjalankan:
1. Buka CMD di folder ini.
2. Jalankan: pip install -r requirements.txt
3. Jalankan: python app.py
4. Buka browser: http://127.0.0.1:5000
